# meta

Notes and documents about **how we work**: the agent team, its setup, process and
tooling. Nothing in here is about the WCL app itself; project work lives in
`documentation/`, `specs/` and `sprints/`.

| Path | What it holds |
|---|---|
| `team-optimisation.md` | The living record of the agent-team redesign (evidence, decisions, proposals) |
| `agent-team/` | The owner's original team prompt and the first role notes (`team-00-*`) |
| `sprints/<date>/` | Per-sprint team analysis: the team-pattern report and the exported team board |

The agent-facing helpers (the team board and the usage script) live in `.claude/team/`.
