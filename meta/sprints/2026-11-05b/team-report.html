P13 first trial: the team knowledge layer

  • Every brief carried its facts (facts.py brief), and every hand-off named the facts it used and the ones it added. Maren: the embedding-timeout and ratio-guard facts "saved real time".
  • 4 facts added, by the developers who found them: the Vertex global cold connection, service-graph virtual-server latency, tool docstrings as prompt text, and a chat drop ending the turn locally. 27 stale facts re-checked in the docs pass: 3 edited, 0 retired. Now 70 facts, lint 0, stale 0.
  • Root causes came fast. Nils found the 12 s global-endpoint cold connection in about 15 minutes, from read-only traces. Ansel read Grafana's node-graph math from the plugin's source map. Both are now facts.
  • Ansel's brief missed the existing stack-scripts-faro-pyroscope-ports fact, so his first stack start collided on port 12347. The brief's fact list goes by footprint, and observability/test/lib.sh wasn't in it.
  • Tomas: comp:team facts went stale on every fact edit, so a facts pass could never end at zero. That was my tool's flaw, and it's fixed: fact files no longer count as changes to the team component.
