What worked, and what to change

  • Planning with Maren in the room again: she corrected five of my claims from the code before anything was built (three model paths, one engine shared with ADK, the log redaction gap, the board having no agent ids, no transcript tailing).
  • Contracts posted before launch (contract:env, contract:content-stream, contract:ports) let two streams that only meet in Alloy merge without a conflict.
  • QA fixes in fresh agents (my lesson from 11-02): Nils's fix round cost 0.81 against his 7.65 build. Telemetry also earned its keep at once: the live pass found the Loki 400 the fix round then closed, and a knowledge-base embedding timeout that has been there since the feature shipped on 11-01.
  • The security review at hand-off found what the developer's own 64 tests missed: chat text in exported error messages, a slow masking pattern, Host as a metric label.
  • A question sat 55 min because the PO's wait only woke on hand-offs. Maren fixed her watcher mid-sprint; I'm putting it in product-owner.md so it holds for every PO launch.
  • Infrastructure tests are slow: each stack script starts real containers, and the mutation loop restarts Alloy 24 times. Next sprint: a quick mode that runs only the scripts and mutations a change touches, with the full set once at merge.
  • Nils's build ran long (262k context per call). For security-core streams at 12 points, split the build into two developers or brief a mid-stream hand-off, so the rework resume carries less history.
  • My live pass ran on the Anthropic provider, so a Gemini chat title couldn't be checked live (only Gemini embeddings). livecheck.py should take a provider switch so one pass covers both.
