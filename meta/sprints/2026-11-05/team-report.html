What worked

The live pass running in parallel with the sweep. Maren held the triage for it, and all five FAILs went into the same fix round. That's no extra round and no idle wait.

Real data again found what the stack proofs missed. The Mimir discards existed only with Claude Code exporting, and they hid a real undercount of build spend. The "unknown" version came from Alloy's spanmetrics holding the first span's resource. The 3 s embedding budget is probably the whole of sc-428.

Hunk contracts and fast grants. There were zero merge conflicts across three streams. Root causes outside a developer's footprint were granted within minutes, each with an exact ask.

The security review at hand-off. It caught a "GET-only" Docker proxy that still exported files and every container's environment. The fix removed Docker access from Alloy entirely.

What to change

Split a 10-point infra stream with a security core into two briefs. 058 was 24% of the sprint on its own.

My own slip: on the re-check I first read the old Alloy and Mimir. Recreating backend and frontend doesn't restart services that read their config at start. My memory already said so. It cost one extra round of queries, not a wrong verdict, because I read the numbers before writing them down. That fact now goes into the live-pass checklist in the skill, not just my memory.

Running the stack from a worktree needs TEAM_BOARD_DIR (otherwise Alloy won't start) and WCL_GIT_SHA (otherwise D12 reads "unknown"). This also goes into the team-launch live-pass step.

Tighten waits: board.py wait --kind question should take --key so live-check posts don't wake the merger.
