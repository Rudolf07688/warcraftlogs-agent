The new rules on their first run

  • Contracts before launch (P16 step 1). Raid summary and class avatar, each with a producer, consumers, an example and a pinning test, plus "as built" updates. Tomas built the Raids page against the example and merged first. 5 streams, zero conflicts.
  • One owner per shared file plus a one-line prep commit (export send). Maren's retro line keeps it.
  • Hostile inputs in briefs, developer rule 10. Every security-core stream wrote hostile-input tests and posted its mutate.py bites. Still, 3 of 4 D18 reviews found Mediums, in two classes the list didn't name: a pooled DB connection held across an external wait, and no rate bound on a new endpoint that calls out. Maren proposes adding both to the list.
  • Reserve backfill (P15). One reserve launched at 23 pts and the cap held at 25. The second reserve went back to the backlog.
  • Live pre-check. Ansel's Battle.net probe was answered in a minute and narrowed his allow-list to the one real render host.
  • Docs pass then late commits. Maren committed a .env.example comment after the docs pass, and the fix round moved code under 7 facts' anchors. I closed both at wrap-up (ca61166). The close-out step should run after the last commit, PO's own included.
