How the WCL Agent fits together

The WCL Agent is a World of Warcraft coaching chat. Its agent, Barnaby, answers questions about raids and Mythic+ runs. It pulls the facts from the Warcraft Logs API, reasons over them with Gemini or Claude models on Vertex AI, and streams the answer into a React chat. Conversations, profiles, guides and every raw Warcraft Logs response are kept in PostgreSQL. A shared Redis cache saves repeat API calls.

Snapshot of branch 026-architecture-design-docs, 2026-10-26.

Whole-system overview

One browser tab talks to one FastAPI process. Chat turns run over a WebSocket. Everything else uses REST under /api. The agent runs inside the backend process; it isn't a separate service.

How to read these docs

  • Three pages. This overview, Backend, data & infra (deployment, API, auth, database, cache, WCL client, PDF reports) and Agent & frontend (agent runtime, models, React UI).
  • Same shape per layer. Each layer says what it does, where it lives (paths from the repo root), the technology with the version range from pyproject.toml, frontend/package.json or docker-compose.yml, why it was chosen and what else was considered.
  • Reasons are sourced. A green bar Cited means the reason is recorded in the repo, and the path below it says where: usually the constitution (.specify/memory/constitution.md), a feature's specs/NNN-*/research.md or plan.md, or documentation/. An amber bar with an Inferred badge means no reason is written down anywhere. The text is then our best reading of the trade-off, not a recorded decision.
  • Planned work carries a Planned, not built badge and a dashed border. Nothing in such a section exists in the code yet.
  • Code wins. These pages are a snapshot from 2026-10-26. Where a spec and the code disagree, the pages describe the code and point out the drift.
  • Diagrams animate their arrows to show which way data flows. Use Pause animations at the top of the page, or your system's reduced-motion setting, to stop them. Sequence diagrams also have a numbered text version for small screens.
