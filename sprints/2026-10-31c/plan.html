Ask about a finished raid→Redis hit?→ no →Postgres store hit, visible to you?→ no →WCL fetch→stored + Redis filled

Risks

  • The WCL client sits on every data path; a bug in the store read could break chats. Mitigation: any store error falls back to WCL, and a kill switch is expected.
  • The visibility rule is new security logic on a global table. Two bypass attempts and the QA security auditor cover it.
  • The shared Redis cache already serves results across tenants; the store must not widen that.
  • Migration 0018 has to be applied before live checks.
