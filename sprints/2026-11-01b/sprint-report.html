Sprint 2026-11-01b: big-report turns that finish, and clean-up

Branch sprint-2026-11-01b Base dd0c2df Code tip 1f4b0e6 Iteration Sprint 2026-11-01b (Shortcut 338) Not merged to main · not pushed

Questions about large reports now finish, and they cost a fraction of what they did. Big report tables reach the agent as a compact top-N list instead of a 60,000-character preview, so it no longer fetches every player one by one. In team-lead's live pass, the top-3 question that used to peak at 397k prompt tokens peaked at 29k, and the chart question that used to end with no answer produced its chart at 53k (was 220k). If a turn still ends with nothing to say, the player gets a clear message instead of the interim line. Clicking a recent raid warms its data in the background, and the agent follows a fixed playbook (2 tool calls, 42k tokens live). Alongside that, the knowledge-base and local-store debt from the last sprint is paid down, and the test suite no longer reads the real .env. All 20 points are delivered and Under Review; nothing was dropped.

Decisions & risks

Key decisions

Pre-fetch warms the cache, doesn't inject

No Warcraft Logs text gets a new path into the prompt, and the chat socket stayed with the clean-up stream. One job per workspace and report (a report-only key would let one workspace's job stand in for another's click), with a 10-minute cooldown.

Partial only when rows are missing

A compact table is flagged partial only when rows were left out. Otherwise the agent's own rule ("fetch the rest when truncated") would send it back to per-player fetches.

Explicit .env switch

Tests turn .env off by a named switch rather than guessing from the test runner, so the app's own behaviour is unchanged and visible.

A Low fixed in rework

The card-click deadlock was rated Low but was a regression from this sprint's own lock and could lose an answer, so it went into the rework instead of the Backlog.

Risks

  • The lane change in the WCL client touches every Warcraft Logs call. The interface is unchanged and the limiter tests pass; the live pass saw no failures.
  • The stored-reports lookup now skips summaries fetched before the visibility window (rare; sc-354 has the full fix).
  • The 20-player table fixture is synthetic. The live pass confirmed the budget on real reports.
  • The tombstone stays per process, as the owner chose and the spec now says.
