Decisions and risks

  • Content capture is off unless WCL_ENVIRONMENT=dev. Compose sets dev, as you decided.
  • Content routing fails closed: build-layer records go to the 7-day content stream unless they are known to be content-free.
  • Grafana: anonymous visitors are Viewers with Explore. The admin password comes from GRAFANA_ADMIN_PASSWORD; while that is unset the admin password is random and unknown.
  • The websocket handler got one granted change, so each chat turn is the root of its own trace.
  • Images are pinned. Alloy's disk queue is a public-preview component, run with the matching stability flag.
  • Risks: the SQLAlchemy instrumentation runs with its version check skipped (it declares support below 2.1). Claude Code 2.1.318 exports no tool output, so masking of tool output is proven by script only. Generic key-word masking also hides some harmless values.
