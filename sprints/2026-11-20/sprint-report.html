Decisions and risks

Decision and reason
Five parallel streams, one owner per file, no scrum master. No shared file and no migration; four mid-sprint grants (a fight-time helper, the Raids page keys, the frame schemas, two test pins) went to whoever needed them, never twice.
Mechanic guides as curated notes plus a lookup tool, not database rows: the knowledge-first route without a migration, working on both providers. Web search stays its own ticket (sc-380).
Tool troubleshooting split by file owner (runtime vs prompt); the story moved to Under Review when both halves were in.
Retraction guard: text before a tool call becomes status only when short (≤600 characters), not before a chart or profile proposal, and never after answer text was kept; a turn that would end empty gets the text back.
The time line is fixed per turn on the Claude path so the cache holds; it can be a few minutes old by a long turn's last call.
Main class/spec reached the context in a sequenced follow-up once the chat socket file was free, instead of granting it twice.

Risks

  • Worst-case Claude call with a 32k budget: rare but long and costly (sc-580).
  • Empty Gemini replies end 2 of 7 turns with "no answer" (old code path, sc-586).
  • Mechanic notes are hand-curated: a new tier needs a new notes file.
