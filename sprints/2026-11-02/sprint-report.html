Decisions, risks and live checks

Key decisions

  • Scope: open bugs and deferred QA items on two epics, no UI or product judgment. board #2
  • Three parallel tier-M streams with disjoint files; the one shared file was split by function. No merge conflicts. #6–9
  • Store breaker: a slow store makes only that workspace skip it; switching it off for everyone needs two workspaces (security review). #52
  • Report tools clean names (no full data marking), plus caps on each name and on the total. #53
  • "Every chat request starts at about 23k prompt tokens" (sc-367) left for the next sprint. #77

Risks

  • Startup now refuses a weak key when SITE_URL is not localhost, including LAN addresses. Deployments need a real SECRET_KEY.
  • Migration 0021 backfills on deploy; it ran cleanly live on 252 rows. Larger stores take longer, but writes are no longer blocked.
  • The kickoff prompt is still slightly above its ~35k target until the per-request base is trimmed (sc-367).
  • The stored-reports lookup cost at scale is unmeasured (sc-371).
