Order and dependencies

  • 036 and 037 run in parallel. Their file footprints don't overlap (board #8): agent.py belongs to 037, and ws.py and migrations belong to 036.
  • Inside 036 the order is 221 → 222 → 223 → 225 → 244. The docs come last so they describe the final RLS policy.
  • Merging: each branch is rebased on the sprint tip, and I run the full suite and the frontend build and tests on the rebased result. Then GitNexus detect-changes, then --no-ff.
  • Wrap-up: a QA sweep scoped to the sprint diff, fixes for critical findings only, QA triage onto the board without duplicates, shortcut-sync, and the sprint review.
