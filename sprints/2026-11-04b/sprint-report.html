Decisions

  • Pricing moved to the end of the build stream, which spread the load across the three streams. Nothing had to be dropped.
  • Browser-to-Postgres trace re-estimated to 3 points. Chat runs over a WebSocket, so the trace context travels inside the message.
  • Shared files were split by section, with owners and contracts posted before launch. There were no merge conflicts and no blocked developers.
  • Log records outside Loki's accept window are dropped, not clamped, and the Loki exporter retries for 24 h instead of forever.
  • Count stats query the raw counters with increase(). This is the one exception to the "aliases only" rule, and a test pins it.
