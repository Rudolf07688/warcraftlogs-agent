QA sweep (bugs and security, sprint diff only)

The sweep proved the board's worst flaw live: the old hook took an agent's identity from any --as text in a command, so both QA agents, Nils and I were relabelled mid-run and read someone else's feed. The fix is merged but only takes effect after the merge to main.

Fixed in one round

  • High: the hook hid the newest entries when its output was cut and never showed them again. Now oldest first, nothing skipped.
  • Medium: reader identity hijack; now only from real board calls, set once.
  • Medium: unchecked addressees reached nobody (and newlines forged lines); now validated.
  • Medium ×3: the browser's loopback guard could be bypassed by a backslash URL, and redirects or scripts weren't checked; now every request is checked inside Chrome.
  • Medium: the stack helper let Docker Compose read the owner's secrets file; now it refuses any checkout that has one.
  • Medium: a leftover Chrome process on a failed start.
  • Medium: a test receipt could claim more than it ran; now checked against the real diff.

Decisions and how they held

  • Contracts on the board before launch (board addressing, receipts, facts, tool names): Vera documented four tools she never read; each builder refined its contract once.
  • New-tools story split so two developers built it in parallel; total stayed 20.
  • Merge the new way: disjoint streams merged without a suite each; one full run at the tip, one after the fix round.
  • Fresh fix agents per author on the same seats, tier S briefs naming each finding.
  • My own small edits on the sprint branch: the stack helper named as the way to run Docker, and the agent files updated for the fix round (seat ids in addressing, the base for receipt checks). team-lead reviewed the agent files at e3cdb85, which includes them.
  • Facts pass: three team facts that went stale every sprint were re-anchored; architecture docs only needed a stamp (no mapped code changed).

Risks

  • Until the merge to main, the live hook keeps the old behaviour, so the next session still runs the old hook.
  • After the merge, every agent re-learns its name on its next board post; until then it sees the full feed (safe direction).
  • The agent-file effect (fewer full suites, fewer calls per point) is only measurable next sprint.
