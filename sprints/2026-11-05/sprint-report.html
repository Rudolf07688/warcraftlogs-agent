QA sweep, live pass and the fix round

The sweep on fcef188 reported 1 Critical, 2 High, 6 Medium and 22 Low findings (qa-reports/2026-11-05-sweep/, local only). The team-lead live pass on the same commit reported 5 FAILs. One fix round, split by author, closed every crucial item:

  • Critical: a profiler tag leak caused by the double SQL tracer. Fixed at the root sc-474.
  • High: the app-shell error boundary sat outside the router, so route errors showed the raw message and stack. Routes now have their own error page.
  • Medium: profile labels carried raw request paths with ids. They now carry route templates only.
  • Live: Mimir silently dropped about 2 samples per second. The cause was a pre-existing transform that collapsed Claude Code's per-session streams, so build-spend figures before this fix undercount.
  • Live: D12 showed the running version as "unknown". Alloy's spanmetrics kept the first span's version; that version is now removed there.
  • Live: D12 attributed only 1 commit, D8 was blank while embeddings failed, and the D9 table was garbled. All fixed.
  • Medium: the D5 first-token "p95" showed one tile per event, and the D11 host line never appeared. Both fixed.
