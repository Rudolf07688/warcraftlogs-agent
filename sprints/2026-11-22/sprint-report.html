Decisions and risks

  • Split by file, not ticket: the chat-turn code had one owner at a time, so 087 followed 084.
  • 180 s per Claude call; a cut answer is marked, never re-run after text (it would repeat on screen).
  • Re-run counts on the turn-stats log line, no new metric.
  • The ticket's cache idea was measured first and replaced: it saved nothing.
  • The time stamp now travels in the turn's message on Claude; a typed fake only misleads that user's own turn (ticketed hardening).
  • The player-comparison bug was older code but on the main coaching path, so it joined the fix round.
  • Risk: the 180 s cut and its re-run still cost tokens and a turn can run long overall (sc-603).
  • Risk: the cache saving starts at turn 4; turns 2-3 rewrite as before (keeping two turns of full results is an earlier product choice).
